# SlugAudit call-provider template

This template is intentionally not compiled. Copy it to `src/evidence/calls_<language>.rs`,
replace the node kinds and extraction logic, then register it from `src/evidence/normalize.rs`.

```rust
use crate::model::{
    EvidenceItem, EvidenceKind, EvidenceOrigin, Position, Span, SpanAvailability,
    char_column, saturating_u32,
};
use serde_json::json;
use tree_sitter_language_pack::Node;

const CALL_NODE_KINDS: &[&str] = &["call_expression"];

pub(super) fn extract_language(source: &str) -> Vec<EvidenceItem> {
    let Ok(mut parser) = tree_sitter_language_pack::get_parser("language-name") else {
        return Vec::new();
    };
    let Some(tree) = parser.parse(source) else {
        return Vec::new();
    };
    let mut items = Vec::new();
    let mut counter = 0usize;
    walk(tree.root_node(), source, &mut items, &mut counter);
    items
}

fn walk(
    node: Node,
    source: &str,
    items: &mut Vec<EvidenceItem>,
    counter: &mut usize,
) {
    if CALL_NODE_KINDS.contains(&node.kind().as_str()) {
        let callee_text = "extract the callee child or source slice";
        items.push(EvidenceItem {
            key: format!("call:{counter}"),
            kind: EvidenceKind::Call,
            origin: EvidenceOrigin::LanguageCallWalker,
            span: node_span(&node, source),
            payload: json!({
                "language": "language-name",
                "callee_text": callee_text,
                "callee_name": callee_text,
                "caller": null,
                "resolution": "unresolved-syntactic",
                "confidence": "high",
            }),
        });
        *counter += 1;
    }
    for index in 0..node.named_child_count() as u32 {
        if let Some(child) = node.named_child(index) {
            walk(child, source, items, counter);
        }
    }
}

fn node_span(node: &Node, source: &str) -> SpanAvailability {
    let start = Position {
        line: saturating_u32(node.start_position().row),
        column: char_column(source, node.start_byte()),
    };
    let end = Position {
        line: saturating_u32(node.end_position().row),
        column: char_column(source, node.end_byte()),
    };
    Span::new(node.start_byte() as u64, node.end_byte() as u64, start, end)
        .map_or_else(
            |_| SpanAvailability::NormalizerUnavailable {
                reason: "call span failed local range validation".into(),
            },
            SpanAvailability::Present,
        )
}
```

## Required tests

Add tests proving:

- ordinary calls are found
- nested calls are found once each
- comments and strings are not reported
- callee text is sliced from source
- spans are present and valid
- unsupported/malformed input does not panic
- language-specific node kinds are documented by a grammar test

## Accuracy rule

Call evidence is syntax evidence. Use `unresolved-syntactic`, `macro`,
`ambiguous`, or another explicit resolution value when the target cannot be
proven. Do not claim compiler-grade resolution from Tree-sitter alone.
